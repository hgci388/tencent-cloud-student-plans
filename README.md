## 七个容易踩的坑

大部分问题不出在买的时候，出在用的过程中。下面这几条都写在活动规则里，但很少被单独拎出来讲。

1. **升配置等于放弃优惠续费**。提升了配置或调整了网络带宽，就不能再按优惠价续费。
2. **不支持降配，也不支持带宽计费模式切换**。买之前想清楚 2核2G 够不够，后面没有后悔药。
3. **控制台续费按官网价**。优惠续费只在活动页生效。
4. **两次续费机会用完就没了**。可选时长是 1、2、3、6、12 个月，怎么分配自己规划。
5. **到期不续、机器被销毁后，不能再买同规格套餐**。这条路是一次性的。
6. **退款后不再保留购买资格**。真要退，等于彻底退出这个活动。
7. **每台服务器只能绑定 1 个 IP**。

## 这台机器适合干什么，不适合谁

它适合拿来练手和放小东西：Linux 常用命令、Nginx 配置、Docker 部署、用 WordPress 搭个自己的站点、跑课程实验、给小程序做个练手后端、放个 Git 仓库。这些场景吃的是“有一台能随便折腾的公网机器”，不是性能。

不适合的场景也很明确：正式对外运营、有明显并发和流量压力的站点，低配加小带宽扛不住；需要 GPU、大内存的任务，这个价位根本不在考虑范围；企业身份采购，规则上就进不来。真要做商业项目，直接看常规 CVM 或轻量服务器的高配档更省事，学生机省下的那点钱不值得拿稳定性换。

另外，如果你的课程只需要一台随时能重装的机器，2核2G 完全够；多花的钱不如留着续费。
